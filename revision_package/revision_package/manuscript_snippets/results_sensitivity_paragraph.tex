\subsection{Retrieval-configuration sensitivity}
On the development partition, we changed one retrieval setting at a time and compared each run with the base configuration (accuracy 67.4\%, error-ranking AUROC 0.851; Table~\ref{tab:sensitivity}). Accuracy ranged from 57.0\% to 69.4\%, but the retrieved evidence and individual predictions changed more than accuracy did: document-set overlap with the base configuration ranged from 0.50 to 0.85, and 4.6\%--24.0\% of predictions changed. Reducing the evidence set to five documents (AUROC difference $-0.064$; 95\% CI $-0.120$ to $-0.005$) or the class shortlist to three classes ($-0.115$; $-0.186$ to $-0.048$) lowered error-ranking AUROC. All other settings, including 10\% and 20\% word dropout and truncation of the query to 80\%, produced AUROC differences whose intervals included zero. Mild query perturbations changed 17--23\% of predictions while overall accuracy changed by less than three points. These analyses were not used to select or tune a configuration, and no multiplicity correction was applied.
